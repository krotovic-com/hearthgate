# Security policy

Hearthgate sits between the internet and a home network, so security reports get priority.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead: go to the repository's **Security** tab and choose **Report a vulnerability**.

Include the version (`hearthgate --version`), what you did, what happened and what you expected. You should get a first reply within 7 days.

## Supported versions

Security fixes go into the latest release. From 1.0, the latest minor release (1.x) gets them, as a patch release.

What Hearthgate defends against, and what it leaves to you, is in the [threat model](docs/THREAT_MODEL.md).
